# Ханьцзы Pro (PWA / Офлайн-версия для GitHub Pages)

Готовая к деплою обновлённая версия приложения для репозитория `rizokrut/hanzi-app`.

## Что нового:
1. **Курс «★ Мои слова» на вкладке «Учить»**: можно учить только свои слова или комбинировать с уровнями HSK 1–9, плюс быстрое добавление и пакетный импорт списков.
2. **Свайпы карточек (как в Anki) и горячие клавиши**: свайп влево (`Снова`), вправо (`Хорошо`), вниз (`Трудно`), вверх (`Легко`), а на ПК — клавиши `1–4`, стрелки и `Space`.
3. **5 методов повторения карточек (+ Умный микс)**: классические свайп-карточки, ввод пиньиня с автоконвертацией цифр тонов (`ni3` → `nǐ`), тест из 4 вариантов, ввод перевода на русском и пропись иероглифа по памяти.
4. **Переработанный экран «Порядок черт» и режим «Написать самому»**:
   - Исправлен переключатель **«Контур: Вкл/Выкл»** внутри режима «Написать самому» (работает мгновенно без сброса режима).
   - В режиме **«Анимация»** добавлены выбор скорости (`0.5x`, `1x`, `1.5x`, `2x`) и бесконечный цикл **«🔁 Повторять: Вкл»**.
   - В блоке «Последовательность черт» под китайским названием черты добавлен **пиньинь** и русский перевод.
5. **Встроенный русский словарь + раздел «Грамматика»**: конструктор китайских предложений из слов, справочник грамматики HSK и генератор листов прописей для печати.
