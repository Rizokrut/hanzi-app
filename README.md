# Ханьцзы

Офлайн-приложение (PWA) для изучения китайского: словарь HSK 1–6 (5000 слов) с русским переводом, анимация порядка черт, карточки с интервальным повторением, тесты, прописи, грамматика.

## Как выложить на GitHub Pages
1. Удалите из репозитория все старые файлы (или создайте новый репозиторий).
2. Загрузите содержимое этой папки в корень репозитория (Add file → Upload files). Папки `data` и `icons` загружайте вместе с файлами.
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/hanzi-app/`.
5. Откройте его на телефоне один раз с интернетом (данные закэшируются), затем «Добавить на главный экран». Дальше работает без сети.

## Обновление
После любых изменений файлов увеличьте номер в `sw.js` (`const V="hanzi-v2"`), иначе телефон будет показывать старую версию из кэша.
